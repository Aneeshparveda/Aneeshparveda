# Contributing — Aneesh Parveda (profile)

This repository holds a personal GitHub profile README. It is not a
software project, and it does not accept feature contributions.

## What is welcome

- Corrections: a broken link, a typo, or a fact about Aneesh's work
  that is out of date or wrong.
- Suggestions, as issues rather than pull requests, for a section
  that would genuinely help a reader (for example a recruiter or a
  collaborator) understand his work.

## How to contribute

1. For a correction, open a pull request with the smallest possible
   change, and say what was wrong and what the correct wording or
   link is.
2. For a suggestion, open an issue first. The maintainer decides
   whether it fits the profile; there is no obligation to accept it.
3. Do not add badges, images, or sections that make claims about
   Aneesh's work that are not true, and do not add personal contact
   details beyond what the profile already shows.

## Scope

The profile points to flagship work (notably NEXUS-32) rather than
repeating it. Substantive project changes belong in the project
repositories, not here.
